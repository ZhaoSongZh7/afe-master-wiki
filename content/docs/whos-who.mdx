Who to reach out to, and for what. When in doubt, start with your manager or the AFE program team.

## Key contacts

| Role | Who | Reach out for |
| --- | --- | --- |
| **Manager** | Assigned before Day 1 | Day-to-day work, priorities, 1:1s, project scope, evaluations |
| **Tech Mentor** | Assigned by manager | Technical questions, code reviews, debugging, skill development |
| **Onboarding Buddy** | Assigned by manager | Day 1 logistics, team culture, Slack channels, "where do I find X?" |
| **Career Mentor** | Matched via Mentor Collective | Professional growth, navigating Amazon culture, confidential guidance |
| **AFE Program Team** | [afe-internship-program@amazon.com](mailto:afe-internship-program@amazon.com) | Program questions, escalations, events, feedback |
| **AUTA Intern Program** | [internprogram@amazon.com](mailto:internprogram@amazon.com) | Return offers, team placement, general intern events, policy questions |
| **HR / MyHR** | [MyHR Live Help](https://atoz.amazon.work/myhr/livehelp/landing) | Benefits, pay, workplace concerns, accommodations |

## How the support structure works

```
You (the intern)
├── Host Team
│   ├── Manager — project, evals, 1:1s
│   ├── Tech Mentor — daily technical guidance
│   └── Onboarding Buddy — Day 1, team culture
├── AFE-Specific Support
│   ├── Career Mentor — professional growth (confidential)
│   ├── AFE Alumni Network — peer support, Slack AMA, office hours
│   └── AFE Program Team — resources, events, escalations
└── Amazon-Wide
    ├── AUTA Intern Program — global processes, return offers
    ├── HR / MyHR — benefits, pay, workplace concerns
    └── External Partners — scholarship, mental health, mentoring
```
