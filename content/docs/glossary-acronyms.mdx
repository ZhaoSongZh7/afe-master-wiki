Amazon runs on acronyms. Keep this page bookmarked — it's one of the biggest
time-savers early on.

## Common acronyms

| Term | Meaning |
| --- | --- |
| **AFE** | Amazon Future Engineer — this scholarship and internship program |
| **AUTA** | Amazon University Talent Acquisition — the team managing all Amazon internships globally |
| **AUTA-X** | Amazon University Talent Acquisition Experience — the team running the intern program wiki and resources |
| **BR** | Bar Raiser — trained interviewer who ensures hiring decisions meet Amazon's bar |
| **CDD** | Cloud Desktop — your remote development machine |
| **CR** | Code Review — submitted via CRUX for peer feedback on code changes |
| **CRUX** | Code Review UX — Amazon's internal code review system (like GitHub PRs) |
| **EAP** | Employee Assistance Program — confidential wellness and counseling support |
| **Embark** | Onboarding platform where your manager uploads your learning plan and project plan |
| **FTE** | Full-Time Employee |
| **GREF** | Global Real Estate & Facilities — equipment & workspace requests |
| **IEF** | Intern Evaluation Form — the document used for midpoint and final evaluations |
| **IEM** | Intern Evaluation Meeting — the formal end-of-internship evaluation discussion |
| **LP** | Leadership Principles — Amazon's 16 guiding principles |
| **MGHD** | Making Great Hiring Decisions — mandatory training for managers who evaluate interns |
| **PTO** | Paid Time Off |
| **SDE** | Software Development Engineer |
| **SDEI** | Software Development Engineer I (entry-level) |
| **SIM** | Simple Issue Management — Amazon's internal ticketing system |
| **1:1** | One-on-one meeting (usually with your manager or mentor) |

## Program-specific terms

| Term | Meaning |
| --- | --- |
| **AFE Role Guidelines** | The [evaluation framework](https://ivy-help-center.talent.a2z.com/article/5CPkBGwcCeMRX9uDckSlEe) written specifically for AFE as a ladder up to the SDE or other intern role |
| **Career Mentor** | A volunteer Amazonian matched to you outside your host team for professional mentorship |
| **Tech Mentor** | A senior engineer on your host team who provides day-to-day technical guidance |
| **Onboarding Buddy** | A teammate assigned to help you navigate your first week (Slack channels, email lists, team norms) |
| **AFE Alumni** | Previous AFE interns now working full-time at Amazon who provide peer support |
| **Midpoint Review** | Formal performance check-in at the halfway point of your internship |
| **Return Internship** | A second internship offer extended to AFE scholars based on evaluation |
| **Embark Plan** | Your personalized onboarding roadmap including trainings and your project plan |
| **Raising the Bar** | The evaluation standard — demonstrating you'd raise the quality of Amazon's current workforce |
| **BT101 / BT102** | Builder Tools workshops (101 = first service, 102 = local development with Brazil) |

## Amazon tools

| Tool | What it is |
| --- | --- |
| **A to Z** | Employee portal — payroll, benefits, time off, trainings ([atoz.amazon.work](https://atoz.amazon.work/)) |
| **Sage** | Amazon's internal Q&A (like StackOverflow) — [sage.amazon.dev](https://sage.amazon.dev/) |
| **PhoneTool** | Employee directory and contact info |
| **Broadcast** | Internal video platform for talks and trainings |
| **Isengard** | AWS account management and access |
| **Apollo** | Internal deployment service for shipping software |
| **Pipelines** | Continuous deployment tool for release automation |
